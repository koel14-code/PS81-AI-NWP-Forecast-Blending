# Documentation Directory

This directory stores architectural documentation, algorithm specifications, and team guidelines for the **Hybrid AI–NWP Multi-Model Forecast Blending System**.

## Document Index
- **Architecture**: Detailed design of data ingestion, feature generation, ML blending engines, and verification.
- **Model Blending Specifications**: Explanations of skill-score weighting, quantile mapping, and regime-aware blending algorithms.
- **Verification Methodology**: Standard meteorological metrics (RMSE, Bias, POD, FAR, ETS) used to evaluate rainfall forecast accuracy.
